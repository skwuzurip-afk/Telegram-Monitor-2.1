# Telegram Monitor 2.1

Консольная программа для Windows, отслеживающая онлайн-статус и изменения профилей пользователей Telegram через собственный аккаунт и официальный API Telethon.

### Возможности
- **Онлайн-статус:** онлайн/офлайн, последний визит и длительность сессий.
- **Изменения профиля:** имя, фамилия, username и описание.
- **Архив аватарок:** сохранение изображений и сравнение старых с новыми.
- **Несколько целей:** до 10 пользователей с отдельными базами данных.
- **Уведомления:** отправка событий через Telegram-бота нескольким получателям с фильтрами.
- **Веб-панель:** обзор, аналитика, история событий и галерея аватарок.
- **История:** поиск, статистика, экспорт TXT/CSV и резервные копии.
- **Фоновый режим:** системный трей, автозапуск и работа без окна.
- **Настройки:** импорт, экспорт и проверка обновлений.

### Установка
1. Установи Python 3.10+ с опцией `Add python.exe to PATH`.
2. Получи `api_id` и `api_hash` на https://my.telegram.org.
3. Запусти `CONFIG.bat` и заполни настройки.
4. Добавь пользователей для мониторинга.
5. Запусти `START.bat` и авторизуйся через Telegram.

Для фонового режима используй `START_BACKGROUND.bat`.

### Веб-панель
После запуска доступна по адресу:
`http://127.0.0.1:8765/`

### Важные ограничения
- Программа видит только информацию, доступную твоему аккаунту Telegram. Приватность пользователей не обходится.
- Проверки выполняются с заданным интервалом, поэтому короткие онлайн-сессии могут быть пропущены.
- Слишком частые запросы могут вызвать временные ограничения Telegram (FloodWait).
- Поддерживается только Windows.
- Мониторинг доступен для пользователей, но не каналов, групп и ботов.

### Безопасность
Все данные хранятся локально в папке `DATA`. Файл сессии `account.session`, `api_hash` и токен бота являются секретными — не передавай их другим людям.

Веб-панель доступна только локально. Данные отправляются исключительно через Telegram Bot API по HTTPS.
